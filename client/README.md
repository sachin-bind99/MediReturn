# MediReturn client

This folder contains the React and Vite front end. From this directory:

```sh
npm install
npm run dev
```

The API base URL defaults to `http://localhost:5000/api`. To use another API,
set `VITE_API_URL` to its full base URL, including `/api`.

See the [project README](../README.md) for server setup and the available lint
and build commands.
